# 创新药械东盟准入协作

协调创新药械面向东盟市场的法规、证据与合作资料。

## 领域资料

`contracts/domain.schema.json` 规定共享资料结构，`fixtures/domain.json` 保存不含真实个人信息的示例。当前参与方包括创新药械企业、药品监管部门、合作医院、境外代理机构。

资料所依据的领域事实如下：

- 活动讨论创新审评和跨境医药交易平台
- 企业需要理解东盟医药市场准入趋势
- 区域合作还涉及患者便捷就医通道

## 本地校验

仓库内的读取模块负责校验示例资料的领域标识、版本、参与方、事实和约束。运行项目自带测试即可检查这些基础资料能够稳定读取。仓库不保存账号、密钥、连接串或真实身份信息。
