# 创新药械东盟准入协作

协调创新药械面向东盟市场的法规、证据与合作资料，并为广西区域服务机构提供统一工作台，承接同一产品同时进入多个东盟国家的准入项目。

## 统一工作台

针对"同一产品在多国注册路径不同、资料版本被合作方误用、企业资料互相不可见"的场景，工作台提供：

- **独立注册路径**：每个产品在每个目标国家有独立路径，记录产品分类、标签语言、法规来源、本地代理与医保采购通道（`src/models.py` 的 `RegistrationPath`）。
- **资料按适用范围关联**：证书、试验数据、翻译件、合作医院、经销资质、集采机会按适用国家关联到路径，逐版本管理（`EvidenceItem` / `EvidenceVersion`）。
- **数据隔离**：企业只能看到本企业资料；合作方只能看到明确授权的资料，以及自己担任本地代理的路径上的申请；服务机构可见全量（`Workbench.visible_*`）。
- **申报版本拦截**：正式申报校验每份证据是否为现行有效版本、适用范围是否覆盖目标国、必需资料类型是否齐全，旧版或跨范围资料直接拦截并留痕（`submit_filing` / `FilingError`）。
- **任务落到责任人与期限**：补件、驳回整改、证书续期、变更应对均为带责任人和期限的任务，支持逾期识别（`Task.is_overdue`）。
- **变更自动联动**：证书到期、适应症调整、生产场地变化、代理终止四类事件自动定位受影响申请并生成对应任务（`apply_change`）。
- **四阶段看板**：页面清楚区分初步接洽、正式申报、获批上市、实际使用，每个申请给出下一步行动（`next_actions`）。
- **准入判断可核对**：每次准入判断定格所采用的证据版本，管理者可核对判断依据的是哪一版资料（`AccessDecision.evidence_refs`）。

## 运行

```bash
python -m unittest discover -s tests          # 运行全部测试
python -m src.workbench --out workbench.html  # 服务机构全量视图（含演示时间线）
python -m src.workbench --as ENT-1 --out e.html   # 企业视图
python -m src.workbench --as P-OLD --out p.html   # 旧合作方受限视图
```

演示场景（`src/seed.py`）：一家广西企业的产品同时进入泰国、越南、印度尼西亚，三国分类、语言、代理、采购要求各异；旧合作方持历史第 1 版证书企图申报被拦截；随后依次演示证书到期、适应症调整、生产场地变化、代理终止的自动影响分析。

## 领域资料

`contracts/domain.schema.json` 规定共享资料结构，`fixtures/domain.json` 保存不含真实个人信息的示例。当前参与方包括创新药械企业、药品监管部门、合作医院、境外代理机构。

资料所依据的领域事实如下：

- 活动讨论创新审评和跨境医药交易平台
- 企业需要理解东盟医药市场准入趋势
- 区域合作还涉及患者便捷就医通道

## 本地校验

仓库内的读取模块负责校验示例资料的领域标识、版本、参与方、事实和约束。运行项目自带测试即可检查这些基础资料能够稳定读取。仓库不保存账号、密钥、连接串或真实身份信息。
