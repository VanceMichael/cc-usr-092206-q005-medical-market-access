# 创新药械东盟准入协作

广西区域服务机构面向创新药械企业的东盟市场准入统一工作台：同一产品在泰国、越南、印度尼西亚各有独立的注册路径与法规来源，证书、试验数据、翻译件、合作医院、经销资质和集采机会按产品×国家的适用范围关联；企业资料按授权隔离，未经授权互不可见。

## 领域资料

- `contracts/domain.schema.json` 规定共享资料结构（JSON Schema 2020-12）
- `fixtures/domain.json` 保存不含真实个人信息的示例数据（示例日期 2026-09-27）

资料以「产品 × 目标国家」为基本单元组织：

| 板块 | 内容 |
| --- | --- |
| `countries` / `regulations` | 三国监管机构、标签语言、本地代理要求与法规来源（含出处链接） |
| `paths` | 每个产品在每个国家的风险分类、注册路径与引用的法规 |
| `artifacts` | 证书、临床证据、标签翻译、合作医院、经销资质、集采机会六类资料，带多版本、有效期与适用范围 |
| `applications` | 准入申请，处于初步接洽 / 正式申报 / 获批上市 / 实际使用四阶段之一，卷宗逐份钉住资料版本 |
| `authorizations` | 资料级授权（active/revoked），是企业资料隔离的依据 |
| `actions` | 补件、驳回、待办，明确责任机构+责任人和期限，自动判定逾期 |
| `events` | 证书到期、适应症调整、生产场地变化、代理终止四类变更事件 |
| `decisions` | 每一次准入判断及当时采用的证据版本，供管理者稽核 |

## 服务能力（`src/`）

- `domain.py` — 资料加载与校验：枚举、ID 唯一、引用完整性、路径与国家一致、卷宗/证据必须钉住真实存在的版本。
- `workbench.py` — 核心服务：
  - **授权隔离**：服务机构看全部；企业只看自有产品；代理只看所代理申请；合作方只看被授权的资料。授权撤销即失去可见性。
  - **补件/驳回**：落到责任机构、责任人与期限，逾期自动标红并按到期日排序。
  - **变更影响分析**：四类事件自动找出受影响申请并给出处置原因（如代理终止后 30 日内需指定新代理、集采资格受限；证书到期反查卷宗引用方）。
  - **旧版申报识别**：接洽/申报阶段的卷宗若钉住已被取代的版本即告警（覆盖「合作方拿旧版资料申报」场景，示例中含被形式审查退回的记录）。
  - **证据版本稽核**：每个准入判断核对当时采用的证据版本——一致 / 判断后已更新 / 判断时已有更新版本 / 判断时已过期。
  - **四阶段视图与下一步行动**：按初步接洽→正式申报→获批上市→实际使用分列，结合待办、变更、到期、集采机会给出企业下一步行动。
- `page.py` — 自包含 HTML 工作台渲染（无外部依赖），内容按查看者过滤。
- `cli.py` — 命令行入口。

## 使用

```bash
# 四阶段总览
python -m src.cli workbench --viewer org-gx

# 未办结补件/驳回（责任人、期限、逾期天数）
python -m src.cli actions --viewer org-gx

# 四类变更事件的受影响申请
python -m src.cli impacts --viewer org-a

# 准入判断采用了哪一版证据
python -m src.cli audit --viewer org-gx

# 旧版资料申报风险
python -m src.cli stale --viewer org-a

# 导出 HTML 工作台（可按不同查看者分别导出，内容自动隔离）
python -m src.cli html --viewer org-gx --out workbench.html
```

主要查看者 id：`org-gx`（广西区域服务机构，全量）、`org-a`（产品持有企业）、`org-b`（同行企业，用于验证隔离）、`org-agent-th`/`org-agent-vn`/`org-agent-id`（三国本地代理）、`org-partner`（被授权单一资料的合作方）。

## 本地校验

```bash
python -m unittest discover -s tests
```

测试覆盖：资料隔离（企业、代理、合作方、撤销授权）、期限与逾期、四类变更影响、旧版申报识别、证据稽核状态、四阶段划分与下一步行动、HTML 页面不跨企业泄密，以及非法资料（钉住不存在的版本、路径与国家不一致、事件缺主体）被拒绝加载。安装 `jsonschema` 后还会额外执行 JSON Schema 契约校验。

仓库不保存账号、密钥、连接串或真实身份信息。
